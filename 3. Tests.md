## Testing & Validation

We created Jest tests in `__tests__/tarjan.test.ts` covering four major areas:

1. **Input-order independence**
   - Verifies that shuffled node/edge input does not change traversal or results
   - Ensures adjacency lists are processed in deterministic ASCII order

2. **Cycle handling**
   - Verifies that a cycle-only graph produces no false bridges or articulation points
   - Validates correct low-link updates for back edges

3. **DFS root, disconnected graphs & isolated nodes**
   - Verifies traversal across multiple components
   - Handles isolated nodes
   - Validates the special articulation-point rule for DFS roots

4. **Invalid graph input**
   - Verifies rejection of invalid coordinates, duplicate node IDs, and self-loops

### Current Test Status

All existing Jest tests pass successfully.
